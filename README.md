# holbertonschool-Fix_My_Code_Challenge

A collection of "Fix My Code" exercises. Each challenge ships with **broken
source code** that already has a goal in mind — the task is to read it,
understand what it is *supposed* to do, find the bug(s), and fix them so the
program behaves correctly.

> The point is **not** to rewrite everything from scratch, but to debug and
> repair existing code with the smallest, cleanest change possible.

## Repository structure

| Directory | Description |
| --- | --- |
| [`challenge/`](challenge/) | The challenges to fix. Each file is one task. |

## Requirements

- Python 3 (scripts use the `#!/usr/bin/python3` shebang)
- A Linux / Unix-like environment

## How to use

1. Pick a challenge inside [`challenge/`](challenge/).
2. Read the matching `README.md` to learn what the code should do.
3. Run the script, observe the wrong behaviour, fix the bug, and run again.

```bash
# make a script executable
chmod +x challenge/0-fizzbuzz.py

# run it
./challenge/0-fizzbuzz.py 89
```
